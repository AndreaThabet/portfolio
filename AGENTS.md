# AGENTS.md

## Project
This is a personal portfolio website built for a class assignment.
The site contains five pages:
- Home
- About Me
- Projects
- Skills
- Contact

## Design
- Keep the design clean, modern, and easy to read.
- Use consistent colors, spacing, and typography on every page.
- The website must work well on both phones and laptops.
- Maintain good color contrast and visible keyboard focus states.

## Development Rules
- Use only plain HTML, CSS, and JavaScript.
- Do not use React, Vue, Bootstrap, Tailwind, npm, or other frameworks/build tools.
- Do not add a backend, database, login, or API keys.
- Use relative file paths.
- Use semantic HTML5 elements.
- Use one h1 per page.
- Give every meaningful image descriptive alt text.
- Keep image files under 500 KB.
- Do not publish a phone number, home address, password, token, or other private information.
- The website must work when index.html is opened directly.

## JavaScript
- Keep the responsive mobile navigation working.
- Keep the second interactive feature working.
- JavaScript should remain simple enough to explain in class.

## Accessibility
- All links and buttons must be usable with the keyboard.
- Interactive controls must have accessible labels.
- Maintain sufficient color contrast.
- Aim for a Lighthouse Accessibility score of 90 or higher on every page.

## Git Workflow
Work on one small task at a time.
After each task:
1. Review the changes.
2. Test the changed feature.
3. Commit with a clear message.
4. Push to GitHub.

Do not use reset or force push to undo work. Revert a commit instead.
